## Description

This is the long description. No limit, and you can use Markdown (as well as in the following sections).

This plugin is a boilerplate to build your plugins off of. It provides a standardized structure and documentation format to speed up development and keep your plugins consistent.

A few notes about the plugin header:

- **Contributors**: Comma-separated list of WordPress.org usernames.
- **Tags**: Comma-separated list of related plugin tags.
- **Requires at least**: The lowest supported WordPress version.
- **Tested up to**: The highest WordPress version tested with.
- **Stable tag**: Points to the version used as the stable release. Use `trunk` if applicable.

## Installation

To install the plugin:

1. Upload `vrtks.php` to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Place `<?php do_action('VRTKS_hook'); ?>` in your templates where needed.
